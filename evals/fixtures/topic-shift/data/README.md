# posts.csv

Short public posts from one hobby forum account, exported 2026-09-02.

- One row per sampled post: `date` (ISO 8601) and `text`.
- Sampling: the export tool kept roughly one post every four days.
- Known gap: no posts were captured from 2026-03-09 to 2026-03-29 because the
  export job was down.
- The account owner sometimes cross-posts, so near-duplicate texts are expected.
